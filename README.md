# Мобильное приложение для отслеживания головных болей

Проект разрабатывается в рамках дисциплины «Групповое проектное обучение (ГПО)». Проект АОИ-2508.

## О проекте

Мобильное приложение для ведения дневника головных болей, отслеживания возможных триггеров и прогнозирования риска приступа.

## Планируемый функционал

- ежедневный дневник;
- фиксация приступов;
- история и статистика;
- учёт сна, стресса, питания и погоды;
- прогнозирование риска головной боли.

## Команда

В проекте участвуют 5 человек.

## Работа с репозиторием

Основная ветка: `main`

Для разработки отдельных задач используются feature-ветки: `feature/название-задачи`

Изменения в `main` вносятся через Pull Request после проверки кода.

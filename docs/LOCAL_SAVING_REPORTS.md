# Черновики, записи без сети и отчёт для врача

Изменения от 5 ноября 2026 года поверх `dev` / `484fb18` (PR №16).

## Возможности

- Формы приступа и самочувствия сохраняют черновик на устройстве. После
  закрытия или перезапуска можно продолжить заполнение. Незаконченный числовой
  ввод тоже сохраняется. «Сбросить черновик» возвращает исходные значения;
  серверная запись при этом не меняется.
- После нажатия «Сохранить» без сети запись остаётся на устройстве и получает
  отметку об ожидающей отправке. Очередь переживает перезапуск. При открытии
  приложения, возврате к нему и каждые 30 секунд в активном приложении
  выполняется повторная отправка. Есть ручная кнопка повтора.
- Кэш, черновики и очередь разделены по аккаунтам и адресам API. Выход
  останавливает отправку записей этого аккаунта; другой аккаунт их не видит.
  Для первого входа и загрузки профиля нужна сеть.
- Каждый выбранный препарат можно оценить: «Помог», «Частично помог»,
  «Не помог». По умолчанию ничего не выбрано; повторное нажатие снимает отметку.
  Результаты видны на проверке записи, в подробностях и в PDF. Удаление
  препарата удаляет его результат.
- В «Обзоре» есть «Отчёт для врача»: выбор периода до 366 дней и сохранение
  либо передача PDF средствами платформы. Включены приступы, длительность,
  интенсивность, симптомы, препараты, результаты и самочувствие по дням.
  Русский шрифт встроен в файл, даты учитывают часовой пояс профиля.
  Сначала нужно отправить ожидающие записи: неполный отчёт не выгружается молча.
- Кнопки добавления и изменения интенсивности увеличены до 44 px;
  у меток выбора увеличены области нажатия.

Прогноз взят из актуального репозитория: оформление и содержимое PR №16
сохранены. Шкала отменена последним указанием пользователя.
Алгоритм и файлы ML-модели не менялись.

## Запуск на ПК

Из корня проекта выполнить `docker compose up --build`, затем открыть
`scripts/run_app.cmd`. Постоянный порт 8732 позволяет восстанавливать данные
в том же браузере. Перед повторным запуском закрыть предыдущий Flutter.
После добавления плагина PDF требуется полный перезапуск фронтенда.

Веб-хранилище привязано к браузеру и адресу страницы. Очистка данных сайта
или профиля браузера удаляет локальные черновики и ещё не отправленные записи.
На Android используется локальное хранилище приложения.

## Backend

- Миграция `0009_merge_offline_weather` объединяет ветки миграций для офлайн-записей и прогноза погоды.
- `medication_effects`: словарь `название: helped | partly | not_helped`.
  Неизвестный результат или препарат, которого нет в записи, даёт 422.
  PUT без этого поля сохраняет прежние результаты.
- `client_request_id`: UUID для POST приступа. Повтор той же операции
  возвращает существующую запись; другая запись с тем же UUID даёт 409.
  Идентификаторы разделены по пользователям. Клиенты без UUID работают как раньше.
- `GET /api/v1/analytics/export?format=pdf&from_date=...&to_date=...&time_zone=...`
  возвращает PDF текущего пользователя с `Cache-Control: no-store`.
  Прежний CSV-экспорт сохранён.

Ошибки проверки полей оставляют ввод в форме. Сетевые ошибки и временная
недоступность сервера сохраняют отправку в очереди. При редактировании одной
серверной записи на разных устройствах действует прежнее правило API:
последнее принятое изменение заменяет соответствующие поля.
